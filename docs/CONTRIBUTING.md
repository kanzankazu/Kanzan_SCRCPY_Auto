# Contributing

Thanks for your interest in contributing to Kanzan SCRCPY Launcher!

## Getting Started

1. Fork this repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test thoroughly with both real devices and AVD emulators
5. Submit a pull request

## Development Setup

```bash
git clone https://github.com/kanzankazu/Kanzan_SCRCPY_Auto.git
cd Kanzan_SCRCPY_Auto
python3 scrcpy_launcher.py
```

## Code Style

- Follow PEP 8
- Keep functions focused and single-purpose
- Add docstrings to new public functions
- Comments in English

## Reporting Bugs

Open an issue with:
- macOS version
- Python version (`python3 --version`)
- scrcpy version (`scrcpy --version`)
- Steps to reproduce
- Expected vs actual behavior
